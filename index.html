Nguồn dữ liệu font (4 tầng)

1. Font cài trên máy tính Đang kiểm tra trình duyệt…

2. Google Fonts Mặc định dùng 48 font có sẵn. Muốn dùng toàn bộ danh sách Google Fonts (hơn 1700 font), dán API key miễn phí vào đây rồi bấm nạp.

Lấy key miễn phí: Google Cloud Console → APIs & Services → bật "Google Fonts Developer API" → Tạo thông tin xác thực (API key). Key này chỉ đọc danh sách font công khai nên an toàn khi để trong mã nguồn công khai; nên giới hạn theo tên miền GitHub Pages của bạn trong phần hạn chế khoá để tránh bị dùng ké.

3. Kho dữ liệu font mở rộng (tự thêm) Nạp một bộ dữ liệu font lớn do bạn tự chuẩn bị, đặt cùng thư mục với trang này (không dính CORS vì cùng nguồn). Tạo file fonts-db/manifest.json dạng mảng [{"label":"Tên hiển thị","url":"fonts-db/ten-file.woff2"}, ...] — nơi gom các font mở, được phép chia sẻ công khai mà bạn muốn mọi người cùng dùng, tách biệt với font riêng trên máy bạn ở tầng 1.

Chưa kiểm tra fonts-db/manifest.json.

4. Trang web nhận diện font khác Trình duyệt không thể tự quét các trang web khác (giới hạn bảo mật CORS, và trang này không có máy chủ riêng để truy vấn hộ) — đây là thao tác thủ công: tải lại ảnh lên các công cụ có cơ sở dữ liệu riêng lớn hơn để so thêm khi cần.
